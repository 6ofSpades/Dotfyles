## First time setup

When opening the browser for the first time, switch to any tab so Tridacty loads, and run:

```
:src
```

Wait some seconds, and while the config loads maybe some warnings can appear.
After everything is done you should see `done.` in the command box. That can take a bit.
Just press `Esc` to exit the command box and that's it.

## Changing config

Change stuff at `tridactyl`, and NOT `tridactylrc`.

Then simply run `:src`.
